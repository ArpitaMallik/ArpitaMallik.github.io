I am Arpita Mallik, a recent Computer Science and Engineering graduate from CUET with a research focus on artificial intelligence, natural language processing, and large language models.

My current interests include LLMs, low-resource and multilingual NLP, parameter-efficient fine-tuning, and trustworthy AI. I am especially interested in developing robust and reliable AI systems that address real-world challenges and have meaningful benefits for people, particularly in healthcare and underserved language communities. I hope to pursue research that not only advances AI capabilities but also makes these technologies more reliable and useful in people's lives. Research Interests

I am interested in making large language models dependable outside the high-resource settings they are usually built and benchmarked for.

  • Large Language Models Parameter-efficient fine-tuning and adaptation; reasoning and generation in non-English settings.
  • Trustworthy AI Reliability and factuality of model outputs in sensitive, high-stakes domains like healthcare and law.
  • Low-Resource NLP Bengali and other under-served languages across text, speech, and multimodal input.
  • AI for Healthcare Emotion-aware and context-sensitive QA systems for women's health in under-served communities.

Selected Projects

Vehicle Insurance Prediction — End-to-End MLOps Pipeline

Designed and deployed a production machine learning pipeline for vehicle insurance prediction. Built a modular, artifact-driven architecture with MongoDB ingestion, schema validation, feature engineering, and model evaluation with threshold-based promotion. Integrated AWS S3 as a model registry, containerised the services, and automated CI/CD through GitHub Actions with deployment on EC2.

Python · scikit-learn · FastAPI · MongoDB Atlas · AWS (S3, EC2, ECR, IAM) · Docker · GitHub Actions

Code

ChatPDF — Retrieval-Augmented Document Assistant

A chatbot that answers questions by retrieving relevant passages from uploaded PDFs. Combines dense vector search over document chunks with generation, so answers stay grounded in the source material rather than in model priors.

Python · LangChain · FAISS · Streamlit · FastAPI · Google Generative AI

Demo Code

Container Job Orchestrator

A distributed job execution platform built on Redis queues and containerised workers. Supports asynchronous dispatch, isolated execution, real-time log streaming over WebSockets and Redis Pub/Sub, and PostgreSQL persistence — the same backend patterns that model-serving pipelines rely on.

Python · FastAPI · Redis · PostgreSQL · Docker · WebSockets

Code

Stress Monitoring and Load-Testing Pipeline

An observability and load-testing setup for FastAPI services. Instruments Prometheus metrics and Grafana dashboards behind a containerised deployment, with configurable k6 load tests reporting throughput, P95/P99 latency, and availability on a three-second collection interval.

Python · FastAPI · Prometheus · Grafana · k6 · Docker

Code
