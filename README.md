# Arpita Mallik – Portfolio Website

Live Site: [https://arpitamallik.github.io/](https://arpitamallik.github.io/)

## Overview

This repository contains the source code for my personal portfolio website. The site showcases my projects, research work, and technical skills, with a focus on machine learning and software development. It serves as a central platform to present my work and provide easy access to my resume and contact information.

## Features

* Project portfolio with descriptions and links
* Section for research and academic work
* Resume access/download
* Contact information and social links
* Responsive design for desktop and mobile devices

## Tech Stack

* HTML5
* CSS3
* JavaScript
* GitHub Pages for deployment


## Project Structure

```
/assets        Static files (images, icons)
/css           Stylesheets
/js            JavaScript files
index.html     Main entry point
```
